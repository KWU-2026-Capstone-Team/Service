# VeriVid Home — reference-based layered UI

2026-10-14. 사용자가 제공한 5개의 실제 서비스 화면을 바탕으로 홈에 적용했다. 이전 A/B 이미지 시안을 구현한 것이 아니라, 이번 레퍼런스의 배경·표면·컨트롤 구성 원리를 사용했다.

## 디자인 적용

- Trainline: 상단 브랜드 컬러와 명확한 기능 진입 구조.
- Copilot: 인디고 배경이 밝은 콘텐츠 면으로 자연스럽게 이어지는 깊이.
- 이동 서비스 화면 및 쇼핑 화면: 간결한 입력 컨트롤과 분리된 캡슐형 하단 메뉴.
- 배달 앱: 입력 방식들을 하나의 시각적 그룹으로 묶는 구조.
- 광고 배너, 검색 기능, 사진 콘텐츠, 가짜 최근 기록 등 VeriVid에 없는 기능은 추가하지 않았다.

상단과 상태 표시줄은 #303C91, 하단 배경은 #EEF1F7로 연결된다. 중앙 녹화 버튼은 브랜드 배경과 밝은 패널 사이에 걸쳐 보인다. 실제 크기는 기존 104dp/크게 보기 112dp를 유지한다. 흰 패널 안에서 파일 선택 두 개를 한 영역으로 묶고, 기록 이동은 구분선 아래의 컴팩트한 행으로 둔다. 정적인 표면·얕은 그림자로 깊이를 만들며 배경 블러나 실시간 스캔 기능은 구현하지 않았다.

## 변경 범위

소스 수정은 `app/src/main/java/com/verivid/app/ui/HomeWorkspace.kt` 하나뿐이다. 공유 테마·다른 화면·화면 이동 콜백·파일 분석 콜백·녹화 권한 및 서비스 코드는 유지했다. 의존성 추가 없음. 홈의 시스템 표시줄 스타일은 다른 화면으로 이동하면 원래 밝은 스타일로 복원된다.

## 확인한 내용

- Android APK 빌드 성공, 기존 에뮬레이터에 업데이트 설치 및 실행.
- 실제 첫 렌더링을 확인하고 패널/메뉴/녹화 버튼의 그림자를 낮춰 재빌드.
- 홈 복귀 시 상태 표시줄 대비를 수정하고 실제 화면으로 확인.
- 녹화 버튼 → 기존 녹화 안내 화면.
- 동영상/이미지 버튼 → 기존 더미 HIGH 분석 결과.
- 기록 링크 및 기록 탭 → 기존 날짜별 기록 화면, 도움말 탭 → 기존 FAQ, 홈 복귀.
- 360dp, 약 411dp, 432dp 화면의 실제 렌더링 확인.
- 360dp에서 크게 보기와 시스템 글자 150% 적용 시 줄바꿈·스크롤 확인. 확대 상태에서 기록 링크를 눌러 이동하는 것까지 확인.
- 크게 보기 ON/OFF 확인. 기본 글자 크기·기본 밀도로 복원.
- 작은 보조 텍스트의 최종 대비 계산: #626E82 / #EEF1F7 약 4.56:1.
- 홈 이외 `app/src/main` 파일 15개는 SHA-256 대조로 변경이 없는지 확인.

## 미수행 및 기존 제한

실제 녹화 권한 승인부터 MP4 생성까지의 전체 과정, 네이티브 파일 선택기, 실제 AI/API, 실기기 및 TalkBack 전체 테스트는 이번 홈 작업에서 수행하거나 새로 구현하지 않았다. 파일 버튼은 기존 더미 분석 콜백을 유지한다. 기존 분석 기록은 시연 데이터다. 서버는 실행하지 않았다.
