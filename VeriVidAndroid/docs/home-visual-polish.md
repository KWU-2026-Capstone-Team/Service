# VeriVid Home — Quiet Tech visual polish

2026-10-14. 홈 화면의 기능·동선·전체 배치는 유지하고 시각 디테일만 조정했다.

## 적용 범위

- 소스 변경: `app/src/main/java/com/verivid/app/ui/HomeWorkspace.kt`만 수정.
- 공유 테마, 기존 화면, 라우트, 권한, MediaProjection, 데이터 및 분석 코드는 변경하지 않음.
- 의존성·폰트 파일 추가 없음. 기존 Android SansSerif 한글 폰트와 시스템 글꼴 배율을 사용.

## 시각적 개선

- 오프화이트 #FAFBFC, 잉크 #1D2330, 인디고 #4B57CD. 작은 보조 텍스트는 대비를 위해 #687386 사용.
- 브랜드 20sp/Medium, 중심 제목 18sp/Medium, 보조 액션 14sp/Medium으로 위계 분리. 브랜드 자간 -0.65sp.
- 원형 버튼 104dp(크게 보기 112dp)는 유지. 광학적으로 대칭인 48dp 프레임+V 심볼을 홈 전용 벡터로 제작.
- 프레임과 V의 선 굵기를 분리하여 모노그램을 강조. 버튼 표면에는 극히 작은 정적인 명암만 적용.
- 파일·설정·기록·하단 탭 아이콘을 24-unit 그리드와 둥근 선으로 통일. 다른 화면의 아이콘은 그대로 유지.
- 버튼 아래 간격 20dp, 제목/설명 8dp, 파일 액션 전 24dp, 기록 링크 전 36dp로 미세 조정.
- 홈 탭에 작은 소프트 인디고 배경 적용. 나머지 탭은 중립색 유지.
- 중앙 버튼을 누를 때만 96.5% 크기와 색상 전환(140ms/120ms). 반복 애니메이션이나 실제 탐지 중이라는 표현 없음.

## 실행 검증

- `assembleDebug` 성공. 기존 Pixel 2 에뮬레이터에 APK 업데이트 설치 및 MainActivity 실행 성공.
- 실제 화면을 확인한 후 중앙 제목의 굵기와 버튼 표면 명암을 한 단계 낮추어 재빌드.
- 360dp, 약 411dp, 432dp 폭의 스크린샷을 육안 검토.
- 크게 보기 ON/OFF, 360dp + 시스템 글꼴 150% + 크게 보기에서 줄바꿈 및 스크롤 접근 확인.
- 중앙 버튼 → 기존 화면 녹화 안내, 영상/이미지 액션 → 기존 더미 HIGH 결과 확인.
- 기록 링크·기록 탭 → 기존 날짜별 기록 화면, 도움말 탭 → 기존 FAQ, 홈 복귀 확인.
- 중앙 버튼을 누른 실제 스크린샷에서 축소 반응 확인. 손을 떼면 기존 녹화 안내로 이동.
- 보조 텍스트 대비 계산 약 4.62:1, 본문 약 15.18:1(지정된 배경 대비). 이는 TalkBack 전체 검증을 대체하지 않음.
- 홈 이외의 `app/src/main` 파일 15개 SHA-256 대조 결과 변경 없음.
- 종료 시 에뮬레이터 밀도 420, 시스템 글꼴 100%, 크게 보기 OFF 및 홈 화면으로 복원.

## 변경하지 않은 제한 사항

현재 영상/이미지 버튼은 기존 더미 분석 콜백으로 연결된다. 실제 네이티브 파일 선택기·모델·API를 이번에 구현하지 않았다. 기록도 기존 시연 데이터이며 홈에 가짜 최근 기록을 추가하지 않았다.

화면 녹화의 권한 허용부터 실제 MP4 생성까지의 전체 과정, 실기기, TalkBack 및 자동화 테스트 스위트는 이번 시각 조정에서 수행하지 않았다. 서버는 실행하지 않았다.
