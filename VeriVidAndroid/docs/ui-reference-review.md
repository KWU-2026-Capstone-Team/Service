# VeriVid UI 레퍼런스 확인 · 적용

확인일: 2026-10-14. 기존 Kotlin/Compose 프로젝트에서만 수정했다.
백엔드, API, 모델, 로그인, 서버는 추가하지 않았다. 분석은 기존 더미 데이터다.

참고: https://wolgyedeoring.vercel.app/start

손님(단체 담당자): 시작·로그인, 홈, 예약 목록, 확정 대기/확정 예약 상세,
사전 주문·참석 조사·가게 정보 펼침, 좌석 배치도, 예약 요청의 모임/일정/조건/메모,
캘린더, 공개 빈자리 상세, 사전 주문, 참석 현황의 빈 상태, 알림 목록, 단체 정보.

사장님: 홈, 예약 상세, 영수증 사진 입력, 메뉴 관리, 직접 추가 바텀시트,
메뉴판 확인, 받은 요청의 빈 상태, 단체 예약 목록, 가게 분석, 미충족 수요,
가게 정보, 공개 좌석 배치도 관리, 빈자리 관리.

예약 확정·취소·요청 전송·결제·주문 저장·참석 링크 생성·사진 업로드·게시·정보 저장은 하지 않았다.
따라서 데이터 변경 이후의 완료 화면, 사진 인식 결과, 새 요청 상세는 검증 대상에 포함하지 않았다.
확인 후 두 데모 계정 모두 로그아웃했다. 계정 정보는 이 문서나 앱에 저장하지 않았다.

관찰: 흰 화면, 옅은 보라/초록의 상태 카드, 차분한 회색 보조 카드,
간단한 선형 메뉴 아이콘, 정보의 그룹화, 접기/펼치기, 하나의 주요 행동 버튼.
VeriVid에는 보라빛 포인트와 카드 그룹화를 적용하되, 네이비 신호등과 세 가지 메뉴를 유지한다.

## 적용한 구성

- 헤더: 왼쪽 방패 아이콘 제거, VeriVid 텍스트만 유지.
- 홈: 장식 전화 그림 제거 → 화면 분석 카드 하나 + 영상/사진 보조 카드 두 개.
- 컬러: 흰 바탕, 아주 옅은 라벤더/회색 카드, 차분한 인디고 버튼, 네이비 신호등.
- 아이콘: 자체 제작한 24px, 1.65px 라운드 선형 벡터로 통일. 새 라이브러리 없음.
- 하단 메뉴: 일반 56dp, 크게 보기 68dp. 시스템 탐색 영역은 별도로 확보.
- 크게 보기: 글씨·여백·버튼 확대. 결과 설명, 상세 링크, 그래프를 숨기지 않음.
  미구현 음성 버튼은 제거해 확대 기능과 혼동하지 않게 함.
- 결과: 상태/이유/의심 구간/행동/세부 점수의 순서와 비단정적 문구 유지.
- 한국어: 문장 단위 줄바꿈과 phrase-aware line break로 어색한 끝 글자 줄바꿈 완화.
- 상세 화면에서 홈 탭 접근 가능하도록 루트 탭 선택 상태 분리.

## 검증 범위

APK 빌드·에뮬레이터 설치 성공. 홈/기록/세 가지 결과/큰 글씨/도움말/녹화 안내/세부 분석 화면을 확인했다.
High/Medium/Low 활성 신호, High 점수 87, 크게 보기에서도 표시되는 그래프, 루트 메뉴 이동을 확인했다.
영상 선택 → 기존 더미 분석 → High 결과 전환과 정상 홈 복귀도 확인했다. 앱 크래시 로그는 비어 있었다.
실제 에뮬레이터 캡처는 `preview/simple-*.png`에 있다.
권한 요청과 실제 녹화는 이번 UI 수정에서 실행하지 않았다.

## 추가 조정: 홈 두 영역 · 날짜별 기록

- 홈의 최근 영상 및 전체 보기 제거. 기록 진입은 하단 분석 기록 메뉴로 일원화.
- 화면 속 영상 확인과 저장된 파일로 확인 두 개의 반투명 카드로 정리.
- 홈 전용 라벤더/블루 빛 배경, 반투명 표면, 얇은 하이라이트 테두리, 그라데이션 시작 버튼.
  실제 배경 블러를 주장하지 않으며, 외부 이미지나 라이브러리 없이 Compose로 렌더링한다.
- 크게 보기에서 파일 선택 버튼은 세로로 배치해 글씨와 터치 영역을 확보.
- 분석 기록은 날짜별로 기본 접힘. 날짜를 누르면 해당 영상만 펼쳐지고, 다른 날짜는 접힘.
- 길게 펼쳐진 필터 칩은 결과 선택 드롭다운 하나로 정리.
- 기록의 날짜는 더미 데이터의 `LocalDate`, 분석 시각과 영상 길이는 별도 필드.
- 추가 파일: `app/src/main/java/com/verivid/app/ui/HomeGlass.kt`.
- 수정 파일: `VeriVidApp.kt`, `VeriIcons.kt`(달력 아이콘), 이 문서.
- APK 빌드·설치 성공. 기본 접힘, 날짜 펼침/접힘, 다른 날짜의 영상 비노출,
  Low 결과 연결, High 필터의 1개 기록 표시를 에뮬레이터에서 검증했다.
- 이번 캡처: `preview/glass-home.png`, `preview/history-dates-closed.png`,
  `preview/history-date-expanded.png`.
