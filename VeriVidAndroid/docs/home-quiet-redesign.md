# VeriVid · Quiet Utility 홈 재설계

## 범위

홈 전용 `HomeWorkspace.kt`만 변경한다. Kotlin / Jetpack Compose / Material 3 및 기존 시스템 글꼴을 유지한다.
`VeriVidApp.kt`, 녹화 서비스, 테마, 아이콘 원본, 분석 기록·결과·도움말 화면 및 분석 콜백은 변경하지 않는다.
의존성, API, 서버, 데이터 저장 기능을 추가하지 않는다.

## 기존 화면 감사

- 강한 블루 카드와 내부 CTA가 시각적 강조를 반복했다.
- 영상/사진이 각각 큰 2열 카드로 표현되어 정보량보다 면적이 컸다.
- 이전 화면은 질문형 큰 제목과 카드 중심의 기능 소개 구조였다.
- 홈의 세 액션은 기존 콜백에 연결된다. 파일 선택 두 액션은 실제 파일 선택기가 아닌 더미 분석이다.
- `historyEntries`는 고정된 시연용 목록이다. 실제 최근 분석 저장/조회 데이터는 연결되어 있지 않다.

## 새 구조

```text
VeriVid                            보기 설정

의심되는 영상,
확인해 보세요.
영상·이미지의 조작 의심 신호를 살펴봐요.

[스캔]  화면 녹화 분석                    >
        다른 앱의 영상을 녹화해요.

파일로 분석
[영상]  동영상 분석                       >
        저장된 영상 선택
        ─────────────────────────────────
[사진]  이미지 분석                       >
        저장된 사진 선택

분석 기록                           전체 보기 >
시연용 분석 · 결과는 참고 정보예요.

      홈           분석 기록           도움말
```

큰 블루 카드·내부 버튼·2열 카드 컴포넌트를 제거했다.
주 액션은 하나의 클릭 가능한 중립색 Surface다. 화살표는 클릭 영역을 중복하지 않는 장식이다.
파일은 흰색 바탕의 리스트이며 텍스트 기준선에 맞춰 필요한 구분선 하나만 배치한다.
실제 최근 데이터가 없으므로 최근 결과/가짜 빈 기록 상태 대신 기존 분석 기록으로 이동하는 메뉴를 사용한다.

## 홈 전용 디자인 시스템

- 배경 #FFFFFF, 텍스트 #1D2433, 보조 #667286, 포인트 #475BD8.
- 주 액션 #F7F8FA, 스캔 아이콘 배경 #EEF1FF, 경계 #ECEEF2.
- 헤더 최소 56dp, 설정 터치 48dp, 일반 제목 26sp / 34sp, 기능 이름 15~16sp, 보조 13~14sp.
- 주 액션 최소 96dp / 크게 보기 120dp, 파일 행 최소 72dp / 크게 보기 88dp.
- 주 액션 Radius 18dp, 아이콘 12dp, 파일 터치 피드백 12dp. 무그림자·무그라데이션.
- 좌우 24dp (360dp 미만은 16dp), 그룹 24dp. 560dp 미만 viewport에서는 세로 간격/패딩 16dp.
- 본문은 자연스럽게 줄바꿈하며 고정 최대 줄 수나 텍스트 축소를 사용하지 않는다.
- 한국어 로케일과 짧은 문장을 위한 균형형 줄바꿈을 홈에만 적용하고 설명 문장을 간결하게 다듬었다.
- 홈 및 설정 시트 스크롤, 시스템 글꼴 배율, 기존 크게 보기와 시스템 inset 처리를 유지한다.
- 기존 벡터 아이콘 재사용. 의미 없는 심볼·장식·AI 이미지·위험 수치 추가 없음.
- 접근성: 제목의 heading 의미, Surface 버튼 및 설정 Switch 상태, Tab 선택 의미 유지.
- 기본 Material 터치 피드백/시트 전환만 사용하며 반복 애니메이션 없음.

정렬, 정보 밀도라는 원리를 홈 전용 구조로 해석했다. 서비스 화면/브랜드 자산은 복제하지 않았다.
[Toss Design System](https://toss.tech/article/toss-design-system)의 일관된 컴포넌트 접근과

[Compose 줄바꿈 설정](https://developer.android.com/develop/ui/compose/text/style-paragraph?hl=ko)을
참고하여 확대 글꼴에서 한국어 어절이 어색하게 끊기는 경우를 보완했다.

## 검증

- `assembleDebug` 최종 빌드 성공 (6초), APK 재설치 및 MainActivity 실행 성공.
- 첫 실제 렌더링 이후 기록 데이터가 없는 화면에 '최근 분석' 제목만 남는 점을 발견해
  실제 연결 구조에 맞는 '분석 기록' 메뉴로 변경했다.
- 393dp 검토에서 하단 참고 문구가 반쯤 보이는 문제를 발견하고 낮은 viewport의 간격 및 주 액션 높이를 보완했다.
- 글꼴 150% + 크게 보기에서 어절 중간 줄바꿈을 발견하고 한국어 로케일/균형형 줄바꿈 및 짧은 설명을 적용했다.
- 기본 411dp: 녹화·동영상·이미지 액션, 기록 링크 및 참고 안내가 첫 화면에 표시됨.
- 360dp: 세 주요 액션과 기록 링크가 표시됨. 하단 참고 안내는 스크롤로 접근 가능.
- 약 393dp 및 432dp: 세 액션과 기록 링크/참고 문구의 잘림 및 수평 겹침 없음.
- 시스템 글꼴 150%: 카드와 행이 텍스트에 맞게 늘어나고 자연스럽게 줄바꿈됨.
- 글꼴 150% + 크게 보기 ON: 설정 토글 체크 상태/완료, 스크롤 후 이미지 및 전체 보기 접근 확인.
- 실제 클릭 검증: 녹화 액션→기존 녹화 안내, 동영상/이미지→기존 HIGH 더미 결과,
  전체 보기→기존 기록, 하단 도움말→기존 도움말, 홈 복귀 및 크게 보기 ON/OFF.
- `HomeWorkspace.kt`를 제외한 모든 `app/src/main` 파일의 작업 전후 SHA256 일치.
- 보조 텍스트 대비 4.87:1, 주 액션 본문 대비 14.61:1, 스캔 아이콘 대비 4.97:1 계산 확인.
  정식 접근성 인증을 의미하지 않는다.
- 최근 AndroidRuntime 오류 로그에 앱 크래시 없음. 서버 실행 및 실제 녹화/네트워크 분석은 수행하지 않음.
- 테스트 후 density 420, 시스템 글꼴 100%, 크게 보기 OFF, 홈 상단으로 복원.
