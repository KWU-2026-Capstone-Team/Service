## 시각적 조정

| 요소 | 이전 | 최종 |
|---|---|---|
| 배경 | 블루 → 회색으로 넓게 흐려짐 | #303F91 → #4355B2 두 색의 상단 영역과 #F8F9FC 배경을 분리 |
| 헤더 | 64dp, 설정 아이콘 배경 원 | 60dp, 아이콘만 표시, 터치 영역 48dp 유지 |
| 녹화 버튼 | 104dp, 심볼 48dp, 카드 겹침 56dp | 100dp, 심볼 42dp, 카드 겹침 32dp |
| 카드 | 반경 28dp, 그림자 1dp | 반경 24dp, 그림자 없음, 은은한 1dp 경계 |
| 파일 영역 | 최소 88dp, 반경 18dp | 최소 76dp, 반경 16dp, 아이콘 22dp 및 간격 6dp |
| 기록 | 배경이 있는 36dp 아이콘 박스 | 배경 박스 제거, 21dp 아이콘과 두 줄 텍스트의 정렬 |
| 하단 메뉴 | 플로팅 캡슐 + 선택 배경 + 그림자 | 흰색 배경과 얇은 상단 선, 아이콘/라벨 색으로 선택 표시 |

크게 보기에서는 녹화 버튼 112dp / 겹침 36dp와 확대 글자를 유지한다. 콘텐츠는 고정 카드 높이가 아니라 글자·컨트롤 크기로 높이가 결정되며, 작은 화면과 큰 글자는 스크롤로 접근한다.

하단 메뉴는 지시문의 **B — Minimal Bottom Navigation**을 선택했다. 중앙의 원형 인터랙션과 둥근 메인 패널을 그대로 살리면서 또 하나의 큰 둥근 컨테이너가 경쟁하는 것을 줄이기 위해서다. 다른 화면의 기존 하단 메뉴는 수정하지 않았다.

홈 전용 색상/기하/글자 토큰으로 역할별 값을 정의했다. 기본 Brand 23sp/SemiBold, Intro 19sp/Medium, Primary Action 21sp/Medium, Section 16sp/Medium, Body 14sp/Regular, Caption 13sp/Regular, Quick Action 15sp/Medium, Navigation 12sp/Medium을 사용한다. 지시문의 수치를 시작점으로 사용하되 실제 한국어 렌더링에서 제목이 과도하게 굵어 보이는 것을 줄였다.

작은 보조 글자 #626E82와 배경 #F8F9FC의 계산 대비는 약 4.90:1이다. 상단/하단 시스템 표시줄 색과 아이콘 대비도 홈에만 적용하며 다른 화면에서는 기존 스타일로 돌아간다.

## Visual QA 및 반복 수정

1. 현재 실행 화면을 `home-refine2-before.png`로 확보하고 실제 화면을 확인했다.
2. 배경 전환 분리, 컨테이너/그림자 제거, 역할별 글자 토큰 및 버튼 겹침 비율을 적용하고 빌드·설치했다.
3. 393dp 첫 캡처 `home-refine2-pass1.png`를 확인했다. 중앙 제목의 굵기가 여전히 강하고 스캔 심볼이 원 안에서 작게 느껴지는 점을 발견했다.
4. 제목을 22sp/SemiBold에서 21sp/Medium으로, 소개 문구를 20sp에서 19sp로 조정했다. 아이콘 42dp 자체 크기를 늘리지 않고 내부 프레임/V의 비율을 조정했으며 카드 선의 대비를 낮췄다.
5. 재빌드 후 두 번째 캡처 `home-refine2-pass2-393.png`를 확인하고 수정 전과 비교했다. 360dp 및 약 412dp 실제 화면도 확인했다.
6. 360×560dp 짧은 화면과 360dp + 시스템 글자 150% + 크게 보기 조합에서 줄바꿈 및 스크롤을 확인했다. 두 조건 모두 기록 링크까지 스크롤하고 실제 기록 화면으로 이동했다.
7. 원형 버튼을 누르고 있는 실제 캡처에서 97% 축소/색상 피드백을 확인했고, 손을 떼면 기존 녹화 안내로 이어지는 것을 확인했다.

스크린샷은 실제 에뮬레이터 캡처이며 이미지 생성 시안이 아니다. 너비는 density 480 = 360dp, 440 = 약 393dp, 420 = 약 412dp 기준이다. 짧은 화면은 1080×1680px / density 480 = 360×560dp로 확인했다.

## 기능 검증

- APK `assembleDebug` 두 번 성공, 기존 에뮬레이터 업데이트 설치 및 MainActivity 실행.
- 원형 녹화 버튼 → 기존 녹화 안내 및 뒤로 가기.
- 영상/이미지 Quick Action → 기존 더미 HIGH 결과 및 뒤로 가기.
- 기록 링크·기록 탭 → 날짜별 기록 화면; 도움말 탭 → FAQ; 홈 복귀.
- 설정 크게 보기 ON/OFF, 시스템 글자 150%, 짧은 화면에서 스크롤 접근.
- 최종 AndroidRuntime 오류 로그에 앱 오류 출력 없음.
- 종료 시 1080×1920px, density 420, 시스템 글자 100%, 크게 보기 OFF 및 홈으로 복원.

## 최종 캡처와 제한 사항

최종 기본 홈: `preview/home-refine2-final.png`.

확대 모드와 작은 화면은 모든 내용을 첫 화면에 억지로 넣지 않고 스크롤한다. 이는 글자·터치 영역을 보존하기 위한 동작이다. 실제 파일 선택기·AI/API는 이번에 새로 구현하지 않았으며 파일 버튼은 기존 더미 분석 콜백을 유지한다. 실제 녹화 권한 승인부터 MP4 생성까지의 전체 과정, 실기기, TalkBack 전체 테스트 및 자동화 테스트 스위트는 미수행이다. 서버는 실행하지 않았다.
