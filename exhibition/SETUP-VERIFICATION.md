# GitHub 전시 설치 검증 — 2026-11-10

## 실제 확인

- Windows 11 x64, Windows PowerShell 5.1, Python 3.12.10에서 저장소 파일을 별도 영문 경로로 복사하여 설치했다.
- 기존 전시 ZIP의 Python을 복사하지 않고 **새 venv를 생성하고 고정 버전 requirements로 실제 설치**했다. pip의 기존 다운로드 캐시는 사용했다.
- 로컬 reference를 사용하는 설치 경로를 먼저 확인한 뒤, reference 옵션 없이 팀 모델·deepGame 원격 저장소에서 지정 커밋을 실제 fetch/checkout하는 기본 경로도 확인했다.
- 모델 5+6개 및 calibration/infer/xai의 식별자가 `dual-branch-d28bda40d902b7d0`과 일치했다. 게임 영상 SHA-256 검증 후 24개와 실제 AI 평가 24개를 새 DB에 복원했다.
- 서버/API와 worker를 `real` 모드로 시작하고 중지했다. 기존 개발 서버는 변경하지 않았다.
- 새 venv 기반 서버에 실제 입력을 업로드하여 CPU 분석 완료, `is_demo=false`, 모델 버전 및 PNG 원본/Grad-CAM 4장 인증 조회를 확인했다.
- 얼굴 없는 영상은 `INSUFFICIENT_FACE_DATA`로 실패했다. 더미·정상 판정으로 대체되지 않았다.
- 게임 5문제의 인증 영상 조회, 답변·채점·해설·실제 AI 비교·전체 결과, 같은 답변 재시도, idle 연결, 영상 부족 409를 확인했다.
- 이 API 연결 시험 전체는 약 56초였으며 **영상 한 건의 처리 시간이나 탐지 성능 수치가 아니다.** 대상 노트북 성능을 보장하지 않는다.
- 업로드 APK의 SHA-256은 `android/VeriVid-exhibition-debug.apk.sha256`과 일치한다. 같은 APK는 앞선 전시 패키지 검증에서 에뮬레이터 설치, 게임 재생/답변/AI 비교, 영상 선택/동의/실제 분석 결과 표시를 확인했다.
- PowerShell 구문 검사와 Git 제외 규칙을 확인했다. runtime/model/영상/DB/로그/ZIP/서명키는 이 커밋에 포함하지 않는다.

## 남은 확인

- 형 노트북 자체의 CPU/메모리/DLL/폴더 권한 및 실행 속도.
- 실제 USB 휴대폰의 드라이버/권한 및 다른 앱 화면 녹화부터 결과까지의 전체 흐름.
- 새 노트북에서의 Android Studio/AVD 설치. ADB 검증에는 기존 공식 SDK 사본을 재사용했다. SDK가 없는 경우 스크립트는 Google 공식 platform-tools를 다운로드한다.
- 다운로드가 차단된 전시장 네트워크. 최초 설치는 전시 전에 인터넷이 가능한 곳에서 끝낸다.
- 영상·모델의 공개 재배포 및 전시 사용 범위. 설치 도구는 원본을 가져올 뿐 라이선스 권한을 부여하지 않는다.

기존 백엔드 API·게임 채점·모델 추론 코드와 Android 비즈니스 로직은 이번 업데이트에서 변경하지 않았다. main 병합이나 외부 서버 공개도 하지 않는다.
