화면은 GitHub Pages에서, 영상 처리는 현재 브라우저를 연 PC에서 실행합니다. GitHub로 영상을 업로드하지 않습니다.

1. 내 PC 백엔드 연결

백엔드와 worker를 실행한 뒤 연결하세요. 브라우저가 로컬 네트워크/기기 접근을 물으면 이 사이트에 허용하세요.

http://127.0.0.1:8000연결 전

토큰은 같은 탭의 새로고침 동안 유지됩니다. 탭을 닫거나 사이트 데이터를 지우면 기존 분석 접근권을 잃을 수 있습니다. API 연결 성공은 worker 실행을 보장하지 않습니다.

처음 실행하는 방법 / 연결이 안 될 때

저장소를 최신 상태로 받은 뒤 아래 명령을 PowerShell에서 실행하세요.

cd <Service 저장소 경로>\deeptector-backend
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe scripts\run_local_demo.py

서버는 loopback에만 바인딩됩니다. 방화벽 포트 개방이나 보안 기능 해제는 필요하지 않습니다. 연결 거부 시 서버 로그와 사이트의 로컬 네트워크 권한을 확인하세요.

자세한 실행 안내

2. 영상 업로드

로컬 demo 실행기는 최대 50MiB를 허용합니다. 분석 완료·실패 후 업로드 사본을 삭제합니다.

선택한 영상이 없습니다.

DEMO는 영상 형식만 확인하고 고정 점수를 반환합니다. 실제 얼굴 검출·딥페이크 판정·XAI 생성은 하지 않습니다.

내 분석 이력

현재 세션의 최근 50건 · 항목을 눌러 결과를 확인하세요.

백엔드에 연결해 주세요.

3. 분석 상태와 결과

대기 중에는 worker가 실행 중인지 확인하세요. 페이지를 새로고침해도 서버 작업은 취소되지 않습니다. 완료 또는 실패한 뒤 삭제할 수 있습니다.
